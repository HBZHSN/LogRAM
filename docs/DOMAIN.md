# 日志领域规则

## 对象与归属

| 对象 | 含义 |
| --- | --- |
| 源日志 | 由外部程序持有的文本文件。查看会话读取当时可见的文件内容，实时模式继续读取追加内容。 |
| 文档 | 一次打开建立的可读视图，关联来源、编码、文件大小与行索引。远程文档另关联主机和 SSH 会话。 |
| 查询 | 作用于文档的文本、正则或组合条件，按日志行判断命中。 |
| 原文页与结果 | 原文页从行号读取连续文本。结果包含命中行号，用于导航、显示上下文及导出。 |

## 规则

| 编号 | 行为 |
| --- | --- |
| DR-01 | 浏览、搜索、刷新均按只读方式访问源文件。NPP 保护已接管日志的只读占位，保留已有未保存快照，并拒绝导出覆盖已打开的源日志。结果导出写入用户指定路径，复验使用独立的目标文件。 |
| DR-02 | 读取支持 UTF-8 与 GBK。行号从 1 开始。末尾即使无换行也可有一条有效日志行，追加可能改变该行的匹配结果。 |
| DR-03 | 高级搜索的包含词满足任一，排除词命中任一即剔除。CLI/MCP 可进一步要求出现全部指定词，且查询词与其他条件同时生效。正则的语法受运行端影响。 |
| DR-04 | 命中数按行统计。CLI/MCP 的结果上限约束返回的匹配行，上下文另计。SSH 也显示搜索命中总数，返回和导出遵循远端限制。 |
| DR-05 | 打开成功后才能分页和查询。追加刷新从旧末行开始重查；检测到截断时，独立 GUI 尝试重开，NPP 暂停实时并提示手动刷新，MCP 在显式刷新时重新加载。 |
| DR-06 | 关闭相应标签释放 GUI/NPP 文档。独立 GUI 还可在窗口失焦达到配置时长后卸载本地文档。CLI 在执行结束时释放文档，MCP 通过 `close_log` 或进程退出释放缓存。 |

文档通常从打开中进入可读状态，查询或增量刷新结束后可继续操作，关闭后释放。取消用于中断当前操作。若内存不足、路径不可读或正则非法，入口返回错误，用户可调整条件或重新打开。截断、断线和返回上限的具体处理见对应实现。 [本地规格](impl-spec/001-local-log.md) · [远程规格](impl-spec/002-ssh-log.md)
