# IS-002 SSH 远程日志打开、浏览和恢复

已实施，适用 1.4.0 的独立 GUI 与 NPP 插件。规范补记于 2026-11-24。 [产品 P-05](../PRODUCT.md#范围与验收) · [DR-01 至 DR-06](../DOMAIN.md#规则) · [ADR-001](../ADR/001-ssh-remote-worker.md) · [任务](../TASKS.md#t-001)

## 流程

1. 从 OpenSSH 配置和显式别名选择主机，经 `ssh.exe -F` 以批处理模式连接。主机身份、认证和跳转沿用用户 SSH 配置。远端工作进程由 `python3` 直接启动，脚本从连接的标准输入加载到远端进程。 [SSH 使用说明](../../README.md#ssh-远程日志) · [会话](../../LogRAM/SshSession.cs)
2. 用户浏览目录或输入路径。`list` 支持路径前缀，最多返回 1000 项。`open` 以登录用户权限只读打开普通文件，检查内存后扫描得到行索引和最长行。`SshLogDocument` 将元数据、页、结果和 `refresh` 状态适配到共用文档接口。 [适配器](../../LogRAM/SshLogDocument.cs) · [远端工作进程](../../LogRAM/Remote/ssh_agent.py)
3. 原文读取使用行号，查询和追加索引在远端执行。客户端使用返回的匹配行号跳转原文。关闭标签或退出释放该 SSH 会话和远端文件。 [文档接口](../../LogRAM.Core/ILogDocument.cs) · [领域规则](../DOMAIN.md#规则)

## 协议与数据

请求使用按行传输的 JSON，包含 `id`、`op` 和 `arguments`。同一会话串行处理操作，并按请求 ID 返回进度、结果、错误或取消。客户端发出取消后消费该请求的终止响应，后续请求可继续。 [会话协议](../../LogRAM/SshSession.cs) · [工作进程](../../LogRAM/Remote/ssh_agent.py)

| 操作 | 返回和边界 |
| --- | --- |
| `open` | 返回规范化路径、字节大小和行数。预留当时可用内存的 20% 或 64 MiB，取较大值。可用量受 Linux 内存和 cgroup v1/v2 剩余额度约束。 |
| `read` | 每次最多 500 行，使用约 1 MiB 回传预算。长行只回传前 16 KiB 的原始字节所对应文本，并标记截断。 |
| `search` | 返回命中总数及已回传的匹配。整次查询最多回传前 1000 条或约 1 MiB，先触达的上限生效。单行截断规则与读取一致，匹配判断使用完整行。导出以客户端已取得的结果为准。 |
| `refresh` | 原文件增长时更新索引并重新匹配原末行及新增行。文件标识变化或长度缩小进入截断分支。 |
| `memory` | 取得远端可用量和工作进程内存，供活动标签状态栏使用。 |

远端正则使用 Python `re`，Linux 下每行限时 2 秒。内存预检扫描正文估算行数与工作内存，建立索引时再次检查，搜索与增量刷新也按当前预算执行。 [远端工作进程](../../LogRAM/Remote/ssh_agent.py)

## 失败与恢复

- 主机验证失败、登录失败或无法启动 Python 时连接报错。修正 SSH 配置或读权限后重新打开。内存不足时拒绝本次工作，索引在构建成功后才生效。 [会话](../../LogRAM/SshSession.cs) · [远端工作进程](../../LogRAM/Remote/ssh_agent.py)
- 断线后通过刷新重连并重新索引。独立 GUI 对实时截断尝试重开，NPP 暂停实时并提示刷新。已断开的远端内存状态显示为不可用。 [GUI](../../LogRAM/MainWindow.xaml.cs) · [NPP 查看器](../../LogRAM.Npp.Viewer/ViewerForm.cs)
