# ADR-001 在 SSH 会话内处理远程日志

状态为已实施的历史补记。实现证据来自 2026-11-09 的 1.4.0 提交 `dd14e04`，补记于 2026-11-24。原始决策方和当时的方案比较待核实。以下比较依据现有实现整理。 [项目说明](../../README.md#ssh-远程日志) · [SSH 会话](../../LogRAM/SshSession.cs)

## 背景与约束

GUI 与 NPP 用户需要浏览 Linux 上持续增长的大文件，并能按行查看上下文。日志读权限由 SSH 登录用户决定，内存预算和带宽会影响能打开的文件及可返回的内容。 [产品范围](../PRODUCT.md#范围与验收) · [DR-04](../DOMAIN.md#规则)

| 方案 | 取舍 |
| --- | --- |
| 下载后交给本地引擎 | 最大程度复用本地精确查询语义，首次打开要传输整个文件，追踪追加需要保持本地副本。 |
| 部署长期运行的远程服务 | 可共享索引和集中控制，需有服务部署、更新和权限运维。 |
| 在每条 SSH 会话中启动内置 Python 工作进程 | 使用既有 SSH 配置与权限，按需传输结果。每个打开文档持有会话和索引，失去连接时要重新建索引。 |

## 已实施方案与影响

1.4.0 采用 SSH 会话内的工作进程。正文、行索引和扫描留在 Linux 主机，Windows 客户端接收有上限的页和结果。代价包括首次打开预检和建索引的两遍扫描，以及远端 Python 正则语法和本地 .NET 的差异。 [远程工作进程](../../LogRAM/Remote/ssh_agent.py) · [IS-002](../impl-spec/002-ssh-log.md)

关闭标签即可结束该会话。网络中断后通过界面刷新重开，已取得的本地日志仍可走本地阅读和搜索。验证覆盖协议、索引、结果上限和隔离主机上的实际连接。 [AC-04](../TEST_STYLE.md#ac-04-ssh-远程查看) · [验证记录](../TASKS.md#t-001)
