# ADR-NNN 决策标题

| 字段 | 填写内容 |
| --- | --- |
| 状态 | 填写 `Proposed`、`Accepted`、`Rejected` 或 `Superseded`。补记既有实现时写明现状及待核实的理由。 |
| 日期 | 填写提案、确认和后续修订日期。历史补记注明原始证据日期。 |
| 决策方和依据 | 链接审批、授权或可核实的历史证据。 |

## 背景与约束

链接受影响的产品需求、领域规则和当前实现，说明为何需要决定。

## 备选与取舍

列出可实施选项及对行为、成本、兼容性和风险的影响。

## 决定与影响

记录选定方案、原因、适用范围和接受的代价。涉及迁移或回退时写明入口、条件和步骤。被替代时与接续 ADR 双向链接。

## 验证

链接对应实现规格、复验场景与任务，给出可观察的通过条件。
