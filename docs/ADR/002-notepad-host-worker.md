# ADR-002 在独立进程中承载 Notepad++ 日志查看器

状态为已实施的历史补记。1.3.3 已有原生分流和独立后台的实测，1.4.0 继续使用。证据见 2026-11-09 插件验证记录，补记于 2026-11-24。原始决策方和当时的方案比较待核实。 [历史验证](../../LogRAM.Npp/VALIDATION.md)

## 背景与约束

用户从 Notepad++ 的打开、最近文件和标签进入工作区。数 GB 日志的内存成本需要计入正文和索引，宿主的普通编辑文档及未保存快照需要保留。 [产品 P-02](../PRODUCT.md#范围与验收) · [领域规则](../DOMAIN.md#规则)

| 方案 | 取舍 |
| --- | --- |
| 宿主按常规载入正文，再由插件查询 | 保留常规文本缓冲区，宿主也承担大日志加载的时间和内存。 |
| 原生 DLL 分流，WinForms 查看器独立加载 | 使用宿主的文件交互，同时让查看器持有日志正文。增加宿主兼容性、窗口嵌入、进程通信与关闭回收的要求。 |

## 已实施方案与影响

原生 DLL 在宿主加载期间接管已保存的 `.log`，宿主保存只读提示，后台进程负责查看、搜索和缓存。宿主通知驱动标签激活和关闭，退出时停止后台。自动分流不可用时可从已打开文档选择 Open current saved file，后台退出后可通过 Restart LogRAM worker 重开。 [原生插件](../../LogRAM.Npp/Plugin.cpp) · [分流实现](../../LogRAM.Npp/LogOpenRouter.cpp) · [插件用法](../../LogRAM.Npp/README.md)

复验同时检查 `.LOG` 自动接管、非日志文档、未保存状态、关闭和 x64/x86 宿主架构。 [AC-01](../TEST_STYLE.md#ac-01-本地桌面查看) · [宿主回归](../TEST_STYLE.md#界面与真实环境) · [任务](../TASKS.md#t-001)
