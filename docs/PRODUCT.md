# LogRAM 产品范围

1.4.0 面向需要查看大型日志的 Windows 用户。典型任务是从已生成的日志中查找事件，定位原文行并读取临近记录。本文依据 2026-11-24 确认的范围补记已发布行为。 [范围确认](INTAKE.md#q-01) · [使用说明](../README.md)

## 范围与验收

| 编号 | 用户与触发场景 | 可观察结果 | 复验 |
| --- | --- | --- | --- |
| P-01 | 桌面用户在独立 GUI 打开本地日志 | 能在标签内搜索、查看原文上下文、导出结果、刷新或跟随追加并关闭文档 | [AC-01](TEST_STYLE.md#ac-01-本地桌面查看) |
| P-02 | Notepad++ 用户通过宿主打开 `.log` 或 `.LOG` | 在同一编辑区查看原文和结果，宿主管理文件与标签，关闭日志标签释放对应缓存 | [AC-01](TEST_STYLE.md#ac-01-本地桌面查看) · [宿主回归](TEST_STYLE.md#界面与真实环境) |
| P-03 | 终端或脚本用户指定文件和查询条件 | 得到可读文本、计数或 JSON，能按行范围限制查询并选取上下文 | [AC-02](TEST_STYLE.md#ac-02-cli-查询) |
| P-04 | MCP 客户端需要反复检索同一日志 | 首次调用加载文件，随后复用缓存，支持读取指定行、查看缓存和释放内存 | [AC-03](TEST_STYLE.md#ac-03-mcp-查询与缓存) |
| P-05 | GUI 或 Notepad++ 用户通过 SSH 查阅 Linux 日志 | 能按主机和路径打开、按页阅读、搜索、跟随追加，在连接中断后通过刷新重连 | [AC-04](TEST_STYLE.md#ac-04-ssh-远程查看) |

## 使用边界

- 操作围绕已存在的日志开展，文件生产和原文编辑由上游工具负责。UTF-8 与 GBK 是本基线的读取编码。 [领域规则](DOMAIN.md#规则)
- 独立程序面向 Windows 10 1809 及以上版本，1.4.0 提供 x64 独立 GUI 包。Notepad++ 插件要求 8.9.8.1 及以上版本且架构匹配，实际宿主证据覆盖 8.9.8.1 x64 和 x86。 [系统要求](../README.md#系统要求) · [宿主证据](../LogRAM.Npp/VALIDATION.md)
- 本地容量取决于可用内存与地址空间。SSH 功能依赖本机 OpenSSH、远端 Linux 上的 Python 3.7 及以上版本以及登录用户的读权限。 [本地规格](impl-spec/001-local-log.md) · [远程规格](impl-spec/002-ssh-log.md)

各入口的发布和补记进度按版本和环境记录。 [任务与证据](TASKS.md)
